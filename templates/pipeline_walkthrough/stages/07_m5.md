# 07 Macro-level Scheduler

What the Macro-level Scheduler reads:
- typed DAG: `../shared/optimizer_outputs/m4_typed_dag.json`
- target: `../shared/optimization_target/m_minus1_target.json`
- optional runtime/offline metrics from the run spec

What the Macro-level Scheduler produces:
- `../shared/optimizer_outputs/m5_execution_plan.json`

Why it exists:
- converts action constraints into batches, parallel groups, guards, fallbacks and pacing policies
